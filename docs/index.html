Network code does not even compile.

Every network API is banned in Morphit’s code. One line that could upload a file, and the build stops:

var http = new HttpClient();

error RS0030: The symbol 'HttpClient' is banned in this project:
Morphit works offline: files never leave the PC

What that means for your files

No uploads, no accounts, no telemetry, no update check. A test also scans Morphit’s own assemblies for network code.

Check it yourself

  1. Resource Monitor, Network tab: Morphit never appears.
  2. Block it in the firewall: everything still works.
  3. Compare the installer’s SHA-256 with the release notes.
